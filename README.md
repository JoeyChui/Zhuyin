# 汉字注音阅读器

一个无需后端的静态网页：粘贴中文文本，即可生成带声调拼音的阅读页面。页面样式参考中文阅读排版，段落首行缩进两格，并会保存最近阅读的文本。

## 使用方式

1. 打开网页后，在输入框中粘贴或输入中文文本。
2. 点击文本框右下角的“注音”。
3. 在阅读页面右下角点击 `+`，可打开历史列表、新增文本、切换文本或删除历史。

输入中的每一个非空行都会作为一个独立段落展示，并自动首行缩进两格。若原文只有一段，请不要在段落内部手动换行。

## 部署到 GitHub Pages

本项目是纯静态网站，不需要安装依赖或运行构建命令。

1. 将 `index.html` 和 `vendor/` 目录一并推送到 GitHub 仓库。
2. 在仓库的 **Settings → Pages** 中选择发布分支（例如 `main`）和根目录（`/root`）。
3. 保存后，GitHub 会提供一个 Pages 地址；任何设备都可以通过该地址使用网站。

## 拼音与网络

注音在访问者浏览器中完成，使用 `pinyin-pro` 的词组级拼音能力处理常见多音字和声调。

- 页面会优先从 CDN 获取该库的当前版本。
- CDN 在 5 秒内未成功加载时，会自动使用仓库中 `vendor/pinyin-pro.min.js` 的本地副本。
- 因此，只要 GitHub Pages 能打开，即使 CDN 临时不可用，也仍可注音。

本地副本的许可证见 [vendor/pinyin-pro.LICENSE](vendor/pinyin-pro.LICENSE)。

## 隐私与数据

文本和历史记录仅保存在当前浏览器的 `localStorage` 中，不会上传到服务器。这也意味着不同电脑、浏览器、无痕窗口之间不共享历史；清除浏览器网站数据后历史记录会消失。

为避免超长内容一次生成大量拼音标记造成页面卡顿，单篇输入上限为 60,000 字。存储空间不足时，页面会提示先删除不需要的历史文本。
